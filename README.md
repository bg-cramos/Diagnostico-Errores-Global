
# Diagnostico Errores Global

Proyecto de diagnóstico y gestión de errores globales.

## Archivos principales

- `agent.py`: agente principal.
- `deploy.py`: lógica de despliegue.
- `requirements.txt`: dependencias de Python.
- `Instructivos.txt`: documentación e instrucciones.

## Instalación

Instalá las dependencias con:

```bash
pip install -r requirements.txt
```
